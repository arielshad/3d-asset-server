A game UI kit is a matched set of interface graphics: buttons in several states, panels and windows, sliders, checkboxes, health and mana bars, icons, cursors and fonts. Using one kit across a whole game keeps menus and the HUD consistent without hiring a UI artist.

This page collects free UI kits with one live search, refreshed automatically. Kenney publishes many CC0 UI packs in different styles, from clean flat buttons to fantasy and sci-fi frames; itch.io creators add pixel-art, hand-drawn and themed kits, each with its own licence shown on the card.

## What to look for

- **Button states.** A usable kit has normal, hover, pressed and disabled versions of each button.
- **Nine-slice friendly.** Panels drawn with even borders scale to any size without stretching their corners.
- **Resolution.** Vector or high-resolution kits stay sharp on large screens; pixel-art kits need integer scaling.
- **Theme.** Match the kit to the game: stone and parchment for fantasy, glowing outlines for sci-fi, rounded pastel shapes for casual games.

Kits come as PNG sprites or sprite sheets that work in any engine, from Unity and Godot to Phaser and plain HTML.
